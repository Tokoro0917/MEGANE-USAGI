## 2. 段階的な目標

一度に全部をやらず、段階ごとに「確実に完走できる」状態を保ちながら進める。

| 段階 | 内容 | 達成基準 |
|---|---|---|
| **Lv1 完走** | 定速での PID ライントレース、交差点の通過、S/G マーカーの検出、S/G エリア内での自動停止 | 練習コースで 10 回中 10 回完走 |
| **Lv2 速度制御** | エンコーダによる速度 FB、ジャイロによる角速度 FB、コーナーマーカーで区間を区切る | 定速 1.5 m/s で安定完走 |
| **Lv3 コース記憶** | 1 走目で区間ごとの距離と角度（エンコーダ＋ジャイロ）を記録 → 曲率を計算 → 2 走目で台形加減速 | 2 走目のタイムが 1 走目の 6 割以下 |
| **Lv4 位置補正** | マーカーと交差点で距離の誤差をリセット。区間をまたいだ加減速 | 5 回走ってもコースアウトしない |
| **Lv5 吸引** | 吸引ファンを追加し、コーナー速度と加速度の上限を上げる | コーナー 2 m/s 以上 |
| **Lv6 仮想ライントレース（最終目標）** | 1 走目に座標の地図を作り、2 走目以降は自分で作った仮想の経路を自己位置推定で追う。機体の幅の範囲でショートカットする（[virtual_line_trace.md](design/virtual_line_trace.md)） | 2 走目でラインからずれた経路を走り、コースアウトしない |
| おまけ | ゴール後に S/G エリアへ自動で戻る（自律賞） | 5 走をノータッチで完走 |

**1 号機（2027年6月）の目標: Lv3 までを確実に動かす。Lv5 の吸引は、基板に入れておくが後回しにしてもよい。**

## 3. ソフトウェアの要点

### マーカー判定（初心者が一番ハマるところ）
- 右マーカーはスタート/ゴール、左マーカーはコーナー
- **交差点では左右のマーカーセンサが同時に反応する** → 左右同時、またはラインセンサが全部白 → 交差点と判定してマーカーを無視する
- 交差点の前後 10cm は直線という規定を使って、交差点を通過したあと一定距離はマーカーを無視する
- 右マーカーを数える: 1 回目でスタート、2 回目でゴール → 減速して S/G エリア内（1m 以内）で停止
- マーカーは「白を検出 → 黒に戻った」ことで確定させる（ノイズ対策で、検出していた距離を確認する）

### コース記憶と速度計画
- 1 走目（探索走行）: 安全な定速で走り、コーナーマーカー間の区間ごとに **走行距離 L と旋回角 θ** を記録する（θ はジャイロの積分）。曲率半径 R = L / θ
- 2 走目: 区間ごとの最高速度を v_max = sqrt(μ g R) の目安から決める（吸引する場合は μ を実効的に上げられる）→ 後ろから前へ減速度の制約を伝えて、台形またはS字の速度プロファイルを作る
- 区間の境界でマーカーを検出したときに、実際の距離と記憶した距離のずれを補正する
- 規定 3-8: コース公開後に情報を入力するのは禁止 → **機体が自分で走って覚える** 以外の方法はない

### 運用
- 5 回の走行で、パラメータを段階的に上げていく（例: 1 回目 探索、2 回目 安全な速度、3 回目以降 攻め）。速度の段階は **機体のスイッチで選ぶ**
- バッテリーは交換できない → 3 分間の 5 走行と吸引に耐えられる容量にし、電圧の低下を速度計画に反映させる
- 走行ログ（センサ、速度、角速度、マーカー）をフラッシュに保存し、あとで PC で解析する。チューニングの効率がまったく違ってくる

## 4. ハードウェアの検討項目（次のステップ）

| 部品 | 候補・考え方 |
|---|---|
| マイコン | STM32（F4/G4。情報量が最多）／ESP32-S3（上位機で使用例あり。無線でログを取れる）／RP2350。**ADC の数、タイマのエンコーダモード、デバッガ** で比較する |
| 駆動モータ | コアレス DC（maxon DCX、Faulhaber、安価なものは中華製）＋ギア。2 輪の差動駆動 |
| エンコーダ | 磁気式（例: AS5047P、AS5600 系、maxon ENX）。分解能は 1024 パルス/回転以上が目安 |
| IMU | 6 軸ジャイロ（LSM6DSV、ICM-42688 など）。角速度の FB とコース記憶に必須 |
| ラインセンサ | フォトリフレクタ 8〜16 個をアレイにする。高さ、間隔、発光の変調（外乱光対策） |
| マーカーセンサ | 左右に各 1〜2 個。マーカー位置に合わせて配置する（寸法は規定の図を確認） |
| モータドライバ | H ブリッジ IC（TB67H450 / DRV8835 系など） |
| 電源 | 2S〜4S LiPo。モータとロジックの系統を分け、電圧監視をつける |
| 吸引 | コアレスモータ＋インペラ、スカート。基板側にドライバと電源の余裕を残しておく |
| 設計ツール | 回路と基板: KiCad、機構: Fusion 360 など、製作: 3D プリンタ、基板発注: JLCPCB など |

**重量目標: 吸引なしで 150g 以下、吸引ありで 200g 前後。**

# 重量配分

**目標: 100g 以下**（2026-10-20 決定）

参考にした値は、KOGUMA-Mk4 の `docs/vehicle.md`（機体の案 v4、合計 59.5g）。

| 部分 | 配分 | 根拠 |
|---|---|---|
| 走行用モータ × 6 | 31.8g | NFP-D8620 5.3g × 6 |
| 足回り × 2（車輪・φ24mm タイヤ・71T・ピニオン 6 個・軸・軸受・磁石・エンコーダ） | 5g | Mk4 は 1 モータ、φ15mm タイヤ、41T で 3.96g。タイヤとスパーが大きい分、実測して見直す |
| モータマウント × 2（3 モータ用） | 4g | Mk4 は 1 モータ用で 2.11g |
| 吸引ファン（モータ 5.3g・ケース・羽根） | 7.5g | Mk4 で 7.49g |
| 電池（2S） | 20g | 2S 300mAh 級。**候補を決めて実測する** |
| 基板＋部品（ラインセンサ、マーカーセンサ、MCU、ドライバ、IMU） | 12g | Mk4 は 6.54g。ラインセンサの分だけ大きくなる |
| フレーム・スカート・滑り板 | 8g | 吸引する範囲が広い分、Mk4（6.28g、マウントと別）より大きい |
| ねじ・配線 | 3g | M2、ナイロンのねじを使う。Mk4 は鉄のねじで 6.62g → 軽くする |
| **合計** | **91.3g** | 余裕 8.7g |

## 気をつけること

- **走行用モータだけで約 3 割（31.8g）**。ここは減らせないので、ほかで軽くする
- **電池が一番の不確定要素**。2S 300mAh の実物の重さを確かめる。容量と放電レートが足りるかは [power.md](power.md)
- Mk4 では、ねじとフレームで配分を大きく超えた（+5.7g、+5.4g）。最初からナイロンのねじ、印刷部品へのねじ山（タップ）で軽くする
- 重心は車軸の近くに置く（加減速で前後の滑り板にかかる力を揃える）
- 部品を決めるたびに、この表を実測の値で更新する

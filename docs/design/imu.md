# IMU

## 決定: LSM6DSR（KOGUMA-Mk4 と同じ）（2026-10-21）

## IMU を 2 個以上載せる案（2026-10-21 検討）

### できること

| 効果 | 内容 | 効く条件 |
|---|---|---|
| **ランダムなノイズを減らす** | N 個の平均をとると、それぞれ独立なノイズは **1/√N** になる（2 個で約 0.71 倍、4 個で 0.5 倍） | ノイズが IMU ごとに独立していること |
| **ゼロ点のずれ（バイアス）の個体差をならす** | チップごとのバイアスのばらつきも、平均すると小さくなる | 同上 |
| **表裏に付けて、共通のずれを打ち消す** | 1 個を基板の表、もう 1 個を裏に付けると、Z 軸（旋回の向き）の符号が逆になる。符号を戻して平均すると、チップの向きに対して同じ向きに出るずれ（電源や温度の影響など）が打ち消し合う場合がある | ずれが 2 個で同じ向き・同じ大きさのとき |
| **故障・異常値の検出** | 2 個の値が大きく食い違ったら、どちらかの異常（衝突の衝撃、通信の失敗など）とわかる | — |
| **加速度の分離** | 2 個を離れた位置に置くと、加速度の差から角加速度や、遠心力の分を分けて求められる | 2 個の距離が十分あること |

上位機では、L1S（中部 2025 で 2 位）が MPU6500 を 2 個載せている（[survey.md](../survey.md)）。

### 効かないこと

- **振動（吸引ファン、モータ）や電源のノイズ** は、2 個に同じように入るので、平均しても減らない
  → IMU の基板を緩衝材の上に載せる（X-303 の例）、ファンの回転数と IMU のサンプリングの関係を見る、電源をきれいにする、などで対策する
- **温度によるバイアスの変化** は 2 個で似た動きをするので、平均しても減りにくい
  → 走る直前に、止まった状態でバイアスを測り直すのが一番効く

### 仮想ライントレースへの効き方

- 向き（ヨー角）はジャイロの積分なので、**バイアスが残るとずれが時間に比例してたまる**。例えばバイアスが 0.01 dps 残ると、40 秒で向きが 0.4° ずれる。その間に 30m 走ると、終わりで横に約 10cm ずれる
- → **一番大事なのは、走る直前のバイアスの測り直し**。そのうえで、IMU を 2 個にするとランダムな部分が約 0.7 倍になる

### コスト

| 項目 | 2 個にしたときの増え方 |
|---|---|
| 重さ | 0.05g 程度（LGA-14、2.5 × 3mm） |
| ピン | CS が 1 本増えるだけ（SPI のバスは共有） |
| 読み出し | 2 個を同じタイミングで読む（DMA で順番に。データの更新は最大 6.66kHz） |
| 部品代 | 数百円 |

### 提案

- **LSM6DSR を 2 個、同じ SPI バスに載せる**（CS を分ける）。1 個を表、1 個を裏に付ける
- ファームウェアでは、「1 個だけ使う」「平均する」を切り替えられるようにして、実測で効果を確かめる
- どちらにしても、走る直前のバイアスの測り直しと、振動の対策をする

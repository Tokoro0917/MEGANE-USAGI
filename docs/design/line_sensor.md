# ラインセンサ

検討開始: 2026-10-20。上位機の構成は [survey.md](../survey.md)、コースとマーカーの寸法は [rules.md](../rules.md)。

## 役割

| 役割 | 見るもの | 必要なこと |
|---|---|---|
| ライン追従 | 幅 19mm の白線の、機体に対する横ずれ | 横ずれを細かく、速く（制御周期ごとに）求める。急カーブ（R10cm）や外れかけでも見失わない |
| スタート/ゴール | 進行方向 **右** のマーカー | 誤検出しない。スタートとゴールの 2 回を数える |
| コーナー | 進行方向 **左** のマーカー | 曲率変化点の位置を知る（コース記憶の区切りと位置補正に使う） |
| 交差 | ラインと直角に交わる線 | マーカーと区別する（左右が同時に白になる） |

## マーカーの位置（2009 年版の規定の図から）

```
                 ← 4cm →← 4cm →
   ライン ████   (すき間)  ▮▮▮▮    ← マーカー（進行方向に 1.9cm、横に 4cm）
   中心  |←0.95→|
         |←───── 約 6.95cm ─────→| マーカーの中心
```

- マーカーはライン中心から約 **4.95〜8.95cm** の範囲（横 4cm）
- → マーカーセンサは、ライン中心から **約 7cm** 横に置く。機体がラインから ±2cm ずれても、マーカーの範囲に入る
- 現行版の規定の図と同じかは要確認

## 上位機の構成（[survey.md](../survey.md)）

- ラインセンサは **16 個が最多**（10〜28 個）。generic だけ 4 個＋モータで動かすセンサアーム
- マーカー用を別に左右に置く機体と、ラインセンサの列の端をマーカー用に使う機体がある（Viper はライン 16＋マーカー 4）
- 使われている素子の例: 発光と受光を分けたもの（OSI3120641E の LED ＋ SCM-014TBT86 のフォトトランジスタ、SFH4059 ＋ SIM-030ST）、反射型の一体品（LBR-123、LBR-127HLD、TPR-105、ITR8307、GP2S700HCP、PT17-21B）
- 16 個を読むために、アナログマルチプレクサ（Viper）や外付け ADC（linelight の MAX11128）を使う例がある
- センサ基板をマグネットコネクタで外れるようにして、衝突で壊れないようにする例（X-303、X-304）

## 設計案

### 1. 個数と並べ方

**決定（2026-10-21）: ラインセンサ 16 個を横一列（直線）に並べる。マーカーセンサは左右に 1 個ずつ（計 18 個）**

- 間隔 7mm なら列の幅は約 105mm。マーカーセンサはライン中心から約 70mm で、列の両端の外側に置く（全体の幅は約 150mm）

上位機の個数（[survey.md](../survey.md)、ラインセンサとして書かれていた数）:

| 個数 | 機体 |
|---|---|
| 4（＋動くセンサアーム） | generic |
| 10 | X-303、SimpleTracer Turbo |
| 12 | Warlock2.6 |
| 13＋サイド 2 | Aslan |
| 14 | LineLumen S3 Mark-2 |
| 15 | SANDEVISTAN、VLT-2 |
| **16** | **APOLLON、白鷺、TLR4、linelight、LN5.8、X-304、Tempestoso、albatross など（最多）** |
| 16＋マーカー 4 | LRX-05A Viper |
| 28 | L1S |


| 案 | 内容 | 長所 | 短所 |
|---|---|---|---|
| **A: 16 個を直線に並べる（おすすめ）** | 間隔 6〜8mm で、幅 90〜110mm | 上位機の定番で、情報が多い。急カーブや外れかけでもラインを見失いにくい | ADC が 16 チャンネル以上必要。基板が横に長くなる |
| B: 8〜10 個 | 間隔 8〜10mm で、幅 60〜80mm | 軽い、ADC が少なくて済む | 外れかけたときに見失いやすい。横ずれの分解能が下がる |
| C: 円弧に並べる | 機体の回転中心を中心にした円弧 | 旋回中もラインとセンサの関係が変わりにくい | 基板の形が複雑。重心から遠くなる |

- 間隔は、ライン幅 19mm に **常に 2〜3 個がかかる** ように選ぶ（重心の計算で横ずれを 1mm 以下で求められる）
- マーカーセンサは左右に 1 個ずつ（ライン中心から約 70mm）。交差の判定は「左右のマーカーセンサが同時に白」と「ラインセンサが全部白」を組み合わせる

### 2. 前後の位置（車軸からの距離）

- センサが車軸より前にあるほど、ラインの先を早く見られて高速で安定する。ただし機体が長くなり、旋回の慣性モーメントが増える
- **急カーブで内側のマーカーセンサがラインを拾う誤検出に注意**: センサの列が車軸より前にあると、カーブの中で機体の向きとラインの接線がずれる。R100 でセンサが車軸の 60mm 前にあると、ずれは約 17°。センサの列が約 20° 傾くと、ライン中心から 70mm の位置にラインが来てしまう
  → マーカーセンサはラインセンサの列より **車軸寄り** に置くか、「ラインセンサが中央でラインを捉えているときだけマーカーを受け付ける」などの判定で防ぐ
- 案: ラインセンサの列は車軸の **50〜70mm 前**。外形が直径 25cm の円に収まるかを確認する

### 3. 床からの高さ

- 素子のデータシートの最適な距離に合わせる（反射型の小型品は数 mm）
- **吸引で床からの高さが一定に保たれる** のは、センサにとって有利。ただし段差や傾斜の変わり目ではずれる
- センサ基板の下面は、スカートや滑り板より高くし、床に当たらないようにする

### 4. 外乱光の対策（規定で「照明の調整は受け付けない」「赤外線 AF への対策は機体側で」とされている）

- LED を **パルスで点灯** し、点灯中と消灯中の値の差を使う（外の光の影響を引き算で消す）
- 機体の下側を覆い、横から入る光を減らす（吸引のスカートとも兼ねられる）

### 5. 読み出し: 外付け ADC をセンサ基板に載せる案（2026-10-21 検討）

**外付け ADC でセンサ基板の上でデジタルにし、SPI で MCU に送る**。

| | 外付け ADC（センサ基板） | MCU の内蔵 ADC |
|---|---|---|
| 配線 | SPI の 4 本＋電源。センサ基板を外せるようにしやすい（マグネットコネクタ） | アナログ 18 本がコネクタを通る |
| ノイズ | センサのすぐそばでデジタルにするので強い。**1 輪 10A 級を PWM する DRV8262 の近くをアナログ線が通らない** | モータの大電流の影響を受けやすい |
| MCU の選び方 | ADC の数で縛られない。小さいパッケージの MCU も選べる | アナログのピンが 22 本前後（センサ 18、ドライバの電流 2、ファンの電流 1、電池 1）必要 |
| タイミング | LED の点灯と ADC の変換を合わせる処理が SPI と DMA 越しになる | タイマと ADC を内部でつなげて合わせやすい |
| 部品 | ADC が増える（数百円〜千円台） | 増えない |

上位機では linelight v2（関西 2025 で 2 位）が外付けの MAX11128 を使っている。

#### 速さの確認

- 18 個 × 点灯・消灯の 2 回 × 制御周期 4kHz = **毎秒 14.4 万回**。1Msps の ADC なら足りる
- 1 周期（250µs）の中で、LED 点灯 → 落ち着くのを待つ → 18 個を変換（約 18µs）→ 消灯 → 待つ → 18 個を変換。フォトトランジスタの応答（数〜数十 µs）を待つ時間を入れても収まる
- SPI は 16 ビット × 毎秒 14.4 万回 ≒ 2.3Mbit/s。DMA で読む

#### 候補（12 ビット、1Msps、SPI）

| 型番 | チャンネル | パッケージ | 電源 | メモ |
|---|---|---|---|---|
| MAX11128（Analog Devices） | 16 | TQFN-28、5 × 5mm | — | linelight v2 が使用 |
| AD7490（Analog Devices） | 16 | **TSSOP-28**（手はんだできる）、LFCSP-32 5 × 5mm | 2.7〜5.25V | |
| ADS7953（TI） | 16 | VQFN-32 5 × 5mm / TSSOP-38 | — | |
| ADS7038（TI） | 8 | WQFN-16、**3 × 3mm** | — | 小さい。8 本のピンは GPIO にもできる |

#### 構成案

- **案 1（おすすめ）: 16 チャンネル（AD7490 か MAX11128）をラインセンサ 16 個に、ADS7038 をマーカーセンサ 2 個に**。ADS7038 の残り 6 チャンネルは予備（センサ基板の温度、追加のセンサなど）。同じ SPI バスで CS を分ける
- 案 2: ADS7038 を 3 個（24 チャンネル）。小さい ADC をセンサの近くに分けて置ける。部品の数は増える

出典: [MAX11128](https://www.analog.com/en/products/max11128.html)、[AD7490](https://www.analog.com/en/products/ad7490.html)、[ADS7953](https://www.ti.com/product/ADS7953)、[ADS7038](https://www.ti.com/product/ADS7038)

### 6. 処理（ファームウェア）

- **キャリブレーション**: 走る前に、各センサの白と黒の値を記録して 0〜1 に正規化する（コースの場所や照明でばらつくため）
- **横ずれの計算**: 正規化した値の重心、または最大値の周りを 2 次関数で補間する
- **見失ったとき**: 最後に見えた側を覚えておき、そちらに戻す。一定時間見つからなければ止まる（コースアウトの判定）

### 7. 機構

- センサ基板はメイン基板と分け、**マグネットコネクタで外れる** ようにする案（衝突対策）。重さとのかね合いで決める
- 重量配分（[mass.md](mass.md)）では、基板＋部品で 12g。センサ基板の大きさがここに効く

## 機体の制約

| 項目 | 規定 | 設計への影響 |
|---|---|---|
| 自律 | スタート操作以外、有線・無線を問わず外部操作は禁止 (1-1) | 無線はログ取得用に限る。走行中のコマンド送信は不可 |
| 寸法 | 床面への投影が **直径 25cm の円** に収まること。高さ **20cm** 以内 (1-3) | 対角を含めて 250mm 未満。実際の上位機は 150〜200mm 程度 |
| 変形 | 形状が変わる場合も常に寸法内 (1-3) | |
| 吸引 | **2023年度から解禁**。外力による接地力の付加は可 (補足) | 吸引ファンは使ってよい |
| 粘着 | タイヤ等への過度な粘着は禁止 (1-4)。溶剤で摩擦を上げるのも禁止 | ウレタン・シリコン系タイヤで勝負 |
| 改造 | 競技中のハード・ソフトの追加、取替、変更は禁止。軽微な修理・調整は可 (1-2) | |
| 書込み | 競技中のプログラム書込み、ROM 交換、外部の開発装置による実行指示は禁止 | パラメータ切替は**機体のスイッチ等**で行う必要がある |
| バッテリー | **競技中の交換は全面禁止** | 持ち時間中の 5 回の走行に加え、吸引も含めて1本で足りる容量が必要 |

## コース仕様

| 項目 | 規定 |
|---|---|
| 走行面 | 黒のつや消し塗装の木材 |
| ライン | 白、**幅 19mm**（ビニールテープ等）。1mm 程度の段差がありうる |
| 全長 | **60m 以下** の周回コース |
| 構成 | 直線と円弧の組合せ。曲率の異なる円弧が連続することがある |
| 最小半径 | ライン中心で **R10cm 以上** |
| 曲率変化点の間隔 | **10cm 以上** |
| 交差 | 交差角 90°±5°。**交差点の前後 10cm は直線** |
| 傾斜 | 部分的に最大 **5°** |
| コース外縁 | ライン中心から 20cm 以上 |

### マーカー

- **スタート/ゴールマーカー**: 進行方向 **右側**。スタートラインとゴールラインの位置に貼る
- **コーナーマーカー**: 曲率が変わる地点の進行方向 **左側**。マーカー同士は重ならない
- スタートライン、ゴールラインの前後 10cm は直線
- **マーカーの寸法（2009 年版の規定の図 3・図 4。https://www.ntf.or.jp/mouse/rt_kitei.html ）**
  - 大きさ: 進行方向に **1.9cm**（ラインと同じ幅）× ラインと直角の向きに **4cm**
  - 位置: **ラインの端から 4cm 離れた所から外側へ 4cm**。ライン中心からは約 4.95〜8.95cm（マーカーの中心は約 6.95cm）
  - スタート/ゴールマーカーは、スタートライン・ゴールラインの位置に、マーカーの中心を合わせて貼る
  - コーナーマーカーは、曲率変化点の位置に貼る
  - 現行版の図も同じかは **要確認**（現行版のページは図が画像で、文章からは読めない）

### スタート/ゴールエリア

```
 進行方向 →

      ゴールライン                 スタートライン
          |<-------- 1m -------->|
   -------+======================+-------  ← ライン
          |  スタート/ゴールエリア |
          |  (ライン中心から左右20cm) |
       [右マーカー]            [右マーカー]
```

- ゴールラインはスタートラインの **1m 後方**。両ラインの間が S/G エリア（ライン中心から左右に各 20cm）
- ゲートの内寸は幅 40cm、高さ 25cm
- 計時センサは **透過型赤外線**。光軸は水平で、床から約 **1cm** の高さ
- → 機体は S/G エリアに置いてスタートし、1周したあとゴールラインを越えて、**スタートラインの手前（1m 以内）で止まる**

## 競技方法

| 項目 | 規定 |
|---|---|
| 持ち時間 | **3 分** |
| 走行回数 | **最大 5 回** |
| 記録 | 各走行のうち **最短タイム** |
| 計時 | スタートラインのセンサが機体を検知してから、ゴールラインのセンサが機体を検知するまで。機体の全体がゴールラインを越えなければ無効 |
| 停止 | 周回後、**S/G エリア内で自動停止し、2 秒以上止まる**。止まらなければその回は無効 |
| コースアウト | 機体の床面投影がラインから完全に外れたらコースアウトで、その回は終了 |
| 停止で終了 | 周回中に 2 秒以上止まると、その回は終了 |
| 試走扱い | スタート後、スタートラインに届く前に停止またはコースアウトしても 1 回とカウント |
| コース情報 | **コース公開後にコース情報を入力するのは禁止**。競技中にスイッチ操作などでコース情報を修正したり、一部を消したりするのも禁止 |
| 接触 | 委員長の許可なく、走行中の機体に触れてはならない |
| 環境 | 通常の室内照明。照明の調整は受け付けない。赤外線 AF などの外乱には機体側で対策する |
| 同タイム | 次点以降の記録で順位を決める |
| 登録 | 1人1台。操作は製作者本人（グループなら代表者） |

## 表彰（評価基準）

- **優勝〜6位**: 最短走行時間
- **自律賞**: 持ち時間内の全走行を **ノータッチ** で完走した機体のうち最速のもの
  → 走行後に S/G エリアへ自分で戻ってくる機能が必要になる
- **スマートトレース賞**: 知能性・自律性への取組み
- **ニューテクノロジー賞**: 新しい要素技術やコンセプトへの挑戦
- **ベストジュニア賞**: 高校生以下
- 特別賞、企業賞

## 出場資格

- 全日本大会に出るには、その年度の **いずれかの地区大会で完走** している必要がある
- → **まず地区大会で完走することが最初の関門**（エントリー方法と締切は各地区大会のページで確認する）

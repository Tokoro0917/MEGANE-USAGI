# マイコン

## 決定: STM32H725RG（VFQFPN68）、KOGUMA-Mk4 と同じ（2026-10-21）

| 項目 | 値 |
|---|---|
| コア / 周波数 | Cortex-M7 / 550MHz、倍精度 FPU |
| RAM / Flash | 564KB / 1MB |
| パッケージ | VFQFPN68（8 × 8mm、裏に放熱パッド）。使える IO は **46 本** |
| 電源 | VFQFPN68 は内蔵 SMPS 専用（3.3V からコア電圧を作る）。外付けのインダクタとコンデンサが必要 |

出典: [Tokoro0917/KOGUMA-Mk4](https://github.com/Tokoro0917/KOGUMA-Mk4) の `docs/spec.md`（「MCU」「MCU の電源」）と `docs/pinmap.md`

### Mk4 と同じにする利点

- ファームウェアの土台（クロック、SPI と DMA、タイマ、内蔵 Flash の使い方、ログ）を共通にできる
- Mk4 で確かめた電源回路（Direct SMPS）とピンの確かめ方（`docs/calc/check_pins.py`）をそのまま使える
- IMU（LSM6DSR）も Mk4 と同じにしたので、読み出しのコードを共通にできる

### 気をつけること（Mk4 の検討から）

- **はんだ付け**: QFN で裏に放熱パッドがあるので、リフロー（ホットプレート・ホットエアー）で付ける。手はんだは難しい
- **電源**: 3.3V は 2S から外付けの降圧で作る。SMPS のインダクタと配線はノイズを出すので、AD7490 とセンサの配線から離す
- **550MHz の条件**: 電圧スケール VOS0 ＋ CPU_FREQ_BOOST。ジャンクション温度 105℃ まで
- **RAM**: 564KB は AXI SRAM、DTCM、ITCM などに分かれている。ログは AXI SRAM（約 300KB）に 250Hz・32 バイトで記録し、約 38 秒残す（[logging.md](logging.md)）
- **内蔵 Flash**: パラメータ、コースの記憶、ログを保存する。消去は 128KB 単位なので、**走行中には書かず、止まっているときだけ書く**

## ピンの見積もり（46 本に収まるか）

| 用途 | 本数 | メモ |
|---|---|---|
| 書き込み・デバッグ（SWD） | 2 | |
| UART（PC とのやりとり、ログの吸い出し） | 2 | |
| スイッチ | 1〜2 | |
| LED（モードと番号の表示） | 4〜7 | Mk4 は 7 本 |
| ブザー | 1 | 任意 |
| エンコーダ MES-6-120PC × 2 | 4 | A/B 相をタイマのエンコーダモードで数える（タイマ 2 個）。オープンコレクタなので 3.3V にプルアップ |
| IMU LSM6DSR（SPI、Mk4 と同じ） | 4 | SCK、MISO、MOSI、CS |
| **ラインセンサ用 ADC AD7490（SPI）** | 4 | SCK、DOUT、DIN、CS。DMA で読む |
| **ラインセンサの LED の点灯** | 1〜2 | タイマの出力で点灯し、AD7490 の変換とタイミングを合わせる |
| モータドライバ DRV8262 × 2 | 4〜6 | PWM 4 本（1 輪 2 本）、nSLEEP、nFAULT。シングル H ブリッジモードでの入力ピンの扱いはデータシートで確認する |
| 内蔵 ADC | 4 | ドライバの IPROPI × 2、ファンの電流、電池の電圧 |
| 吸引ファンの PWM | 1 | |
| **合計** | **約 32〜39** | 46 本に収まる見込み。残りは 7〜14 本（ログは RAM と内蔵 Flash に残すので、外付けのメモリ用のピンは要らない。[logging.md](logging.md)） |

- 割り当てを決めたら、Mk4 の `docs/calc/check_pins.py` と同じ方法（ST の公開しているピン定義）で、ピンと機能の組み合わせを確かめる
- DRV8262 の VREF（ハードの電流制限）は、抵抗の分圧で固定にするか、MCU から電圧を出して変えられるようにするかを決める

## Mk4 と違うところ

| 項目 | Mk4 | MEGANE-USAGI |
|---|---|---|
| センサ | 壁センサ 4 個を内蔵 ADC で読む | ラインセンサ 14＋マーカー 2 を **外付けの AD7490** で読む（SPI が 1 系統増える） |
| モータドライバ | MP6551 × 2（電流は下側 FET、各 2 本） | DRV8262 × 2（IPROPI、各 1 本） |
| 電源 | 3S | 2S |

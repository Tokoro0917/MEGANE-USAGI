# 駆動系の検討: 1 輪あたり 3 モータ

## ねらい

**安いモータを使って、加速度を上げる。**
1 つのホイールギア（スパー）に、3 つのピニオン（モータ）を噛み合わせる。

```
            [M2]
              ●
     [M3]●    ◎    ●[M1]     ◎ = 車軸とスパー、● = ピニオン
              |
          ===タイヤ===
    ─────────────────── 床（車軸の真下にはモータを置けない）
```

- 同じ輪の 3 個は並列につなぎ、1 つのドライバで回す。エンコーダは 1 輪に 1 個（車軸側に AS5047P）
- 制御上は普通の 2 輪差動駆動と同じ

## 前提（2026-10-20）

- **機体重量 100g 以下**（[mass.md](mass.md)）
- **吸引 600gf**（[suction.md](suction.md)）→ グリップの上限は約 69 m/s²（μ = 1.0）
- **電源 2S**（[power.md](power.md)）
- **タイヤ φ24mm、スパー 71T**（ピニオンは Mk4 と同じ 13T、m0.3 と仮定）

## 採用モータ: NFP-D8620-3665-3-7.4（KOGUMA-Mk4 と同じ）

出典: [Tokoro0917/KOGUMA-Mk4](https://github.com/Tokoro0917/KOGUMA-Mk4) の `docs/spec.md`（販売ページ: https://nfpshop.com/product/8-6-x-20mm-coreless-dc-motor-high-efficiency-low-noise ）

| 項目 | 値 |
|---|---|
| 定格電圧 | 7.4V |
| 巻線抵抗 | 1Ω |
| トルク定数 | 1.47 mNm/A |
| 無負荷回転数 / 無負荷電流 | 46,000rpm / 140mA |
| 停止トルク / 停止電流 | 10.7 mNm / 7.41A |
| 重さ / 大きさ | 5.3g / φ8.6 × 20mm |
| 軸 | φ1.2mm、長さ 5.1mm、片軸（モータ側にエンコーダは付かない） |

- **受注生産で約 4 週間かかる**。6 個＋予備を早めに注文する
- 連続で流してよい電流は公表されていない → ドライバで電流を測り、ソフトで制限する（Mk4 と同じ方針）
- Mk4 の足回り（m0.3 のギア、LF-630、AS5047P）の設計資産を流用できる

## 見積もり

`tools/drive_estimate.py` で計算した。条件は、電圧 7.4V、効率 0.8、モータ以外 68g（3 個/輪で合計 100g）。
加速度の単位は m/s²。モータの上限で、グリップは考えていない。

| タイヤ | 減速比 | 電流上限/個 | 1個/輪 (79g) | 2個/輪 (89g) | **3個/輪 (100g)** |
|---|---|---|---|---|---|
| φ20mm | 4.38 (13T:57T) | 2.4A | 29.6 | 52.2 | 70.0 |
| **φ24mm** | **5.46 (13T:71T)** | **2.4A** | 30.8 | 54.2 | **72.7** |

0〜6 m/s のどの速度でもほぼ同じ値になる（このモータでは電圧に余裕があるため）。

## わかったこと

1. **吸引 600gf のグリップ（約 69 m/s²）を使い切るには、3 モータが必要**
   - 1 個/輪だと、グリップに届くには 1 個あたり 5A 以上流す必要がある。発熱が大きすぎる
   - 3 個/輪・タイヤ φ24mm・13T:71T なら、**1 個あたり約 2.3A** でグリップの上限に届く
2. **3 個にすると、同じ加速度での発熱が 1/3 になる**
   - 1 個あたりの電流が 1/3 になるので、発熱 I²R の合計も 1/3
   - ロボトレースは 1 周 10〜20 秒の加減速を最大 5 回繰り返す。マウスより発熱の余裕が大事
3. **このモータでは、加速度を決めるのは電圧ではなく電流（＝発熱）**

## モータに流す電流の上限

上の「2.3〜2.4A/個」は **モータの限界ではない**。吸引 600gf・μ = 1.0 のグリップの上限（68.7 m/s²）に届くのに必要な電流から逆算した値。
モータ 1 個あたり 1A で、加速度は約 32 m/s² 増える（3 個/輪、100g、13T:71T、φ24mm）。

### モータ自体はもっと流せる

| 制約 | 1 個あたりの上限 | メモ |
|---|---|---|
| 電圧（7.4V） | 0 m/s: 7.4A、2 m/s: 6.1A、4 m/s: 4.7A、6 m/s: 3.4A | 速くなるほど逆起電力で流せる電流が減る。6 m/s でも 3.4A で約 104 m/s² |
| ドライバ（DRV8262、1 輪あたり） | 過電流保護 16A → **約 5.3A**、実効値 10A → 約 3.3A | 3 個で分けた値 |
| 電池（2S 300mAh 60C） | 18A（6 個とファンの合計） | 6 個で分けると約 2.7A。ピークをこれ以上にするなら電池を見直す |
| 発熱（巻線抵抗 1Ω） | 2.3A: 5.3W、3A: 9W、4A: 16W、5A: 25W | 連続で流してよい電流は公表されていない。**実測して決める** |

- 電流の上限を上げても、**グリップを超えた分はタイヤが滑るだけ**。加速度を上げるには、まずグリップ（μ と吸引力）を上げる必要がある
- 実際のタイヤの μ が 1.0 より大きければ、必要な電流も増える: μ = 1.2 で 2.7A、μ = 1.5 で 3.4A
- **減速のほうが電流が大きくなる**: 走っている向きと逆に電圧をかけると、逆起電力が足し算になる。6 m/s から全力で逆転させると約 11.4A 流れる。電流の制限は、加速だけでなく減速でも効かせる

### 決め方（案）

1. **ソフトの上限**: グリップに届く電流（μ を測ってから決める。今の見込みで 2.3〜3.4A）＋少しの余裕
2. **ハードの保護**: DRV8262 の ITRIP を 1 輪 15A 前後（1 個 5A 相当）に設定。ソフトが暴走したときの保護
3. **発熱の確認**: モータを止めた状態（ロック）で 3A、4A、5A を流し、何秒で何℃になるかを測る。加減速の短いピーク（0.1〜0.3 秒）なら、平均より大きく流せる可能性がある
4. 走行ログで、1 周の電流の実効値とモータの温度を見て見直す

## ギア: タイヤ φ24mm、13T:71T（5.46）（2026-10-20 決定）

| 項目 | 値 |
|---|---|
| 減速比 | 71 / 13 = **5.46** |
| スパーの歯先の半径 | (71 + 2) × 0.3 / 2 = 10.95mm |
| スパーの歯先と床のすき間 | 12 − 10.95 = **1.05mm**（Mk4 と同じ） |
| 車軸とモータの軸間 | (71 + 13) × 0.3 / 2 = **12.6mm** |
| 無負荷の最高速 | 約 11.1 m/s（走行で使う速度 〜6 m/s には十分） |

- 加速度は「減速比 / タイヤ半径」で決まる。5.46 / 12mm = 0.455 で、φ20mm・57T（0.438）より少し大きい
- ピニオンは 13T と仮定した。**ピニオンの歯数が決まったら、この表を計算し直す**

## 配置の検討

- 車軸からモータ中心までは 12.6mm。モータ同士がぶつからない角度の間隔は **約 40° 以上**（2 × asin(4.3 / 12.6)）
- 車軸の高さは 12mm。**車軸の真下には置けない**（モータの下端が床にぶつかる）
- → 例: 前（0°）・上（90°）・後ろ（180°）の 3 か所。前と後ろは、モータの下端が床から約 7.7mm
- 間隔が 40° で済むので、3 個を上側の 180° の範囲に寄せて置くこともできる。吸引ファン、ラインセンサ、基板との干渉を見て決める

## 注意点

| 項目 | 内容 |
|---|---|
| 電流 | 3 個/輪、2.3〜2.4A/個で、ピーク時に合計約 14A |
| ドライバ | **1 輪に 1 個**。3 個を並列につなぐ。1 輪あたり約 7A（[motor_driver.md](motor_driver.md)） |
| ギア精度 | 3 か所の軸間距離がずれると、ガタや引っかかりが出る。Mk4 と同じく、軸受とモータを 1 部品で持つマウントにする |
| 負荷の偏り | ギアでつながっているので回転は揃うが、特性の差で電流が偏る。同じロットで揃える |

## 進め方

関西地区大会での完走を危うくしないように、**「3 個まで載せられるが、1 個でも走れる」設計** にする。

1. NFP-D8620 を **7 個（走行 6＋ファン 1）＋予備で注文**（受注生産で約 4 週間）
2. 届いたら 1 個で、無負荷回転数、電流、発熱（2.4A を何秒流せるか）を測る → `drive_estimate.py` の電流上限を決める
3. 3D プリンタで、片輪分の 3 モータマウントを試作する（Mk4 の `mechanical/motor_mount/mount.py` がベースにできる）。噛み合わせ、電流の偏り、発熱を確認する
4. タイヤの μ を測って、グリップの上限を確定させる

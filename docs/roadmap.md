# 開発ロードマップ

目標: **2027年度の関西地区大会で完走する**（全日本大会の出場権も得られる）。そのために **2027年6月までに 1 号機を完成** させる。

> 2027年度の日程は未発表。2026年度の関西地区大会は 7/25 が試走会、7/26 が本番だった。
> 日程とエントリー締切が発表されたら、この表を更新する。

| 時期 | 設計 | プログラム | 運用・イベント |
|---|---|---|---|
| 2026/10–11 | 規定・攻略の調査（済）、要求仕様、部品の選定 | 開発環境の構築 | 練習コースを用意（ショートトラック） |
| 2026/11 | | | **全日本学生大会 (11/21–22) を見学** |
| 2026/12 | 回路設計（KiCad）、機構の検討 | 開発ボードとブレッドボードでセンサとモータの基礎を確認 | **東日本地区大会 (12/19–20) を見学** |
| 2027/01 | 基板レイアウト、機構 CAD | ドライバ層（ADC、エンコーダ、IMU、PWM、ログ） | |

段階 Lv1〜Lv5 の定義は [strategy.md](strategy.md) を参照。

関西で完走するのに必要なのは **Lv1（確実な完走）だけ**。スケジュールが遅れたら Lv2 以降を削り、Lv1 の信頼性を最優先する。

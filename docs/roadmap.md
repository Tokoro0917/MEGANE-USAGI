# 開発ロードマップ

目標: **2027年6月までに 1 号機を完成**させ、2027年度の地区大会で完走 → 全日本大会（2028年2月頃）の出場権を取る。

> 2027年度の大会日程は未発表。2026年度と同じなら、最初の地区大会は 7月下旬の関西地区。
> 出場する地区大会を決めたら、この表を更新する。

| 時期 | 設計 | プログラム | 運用・イベント |
|---|---|---|---|
| 2026/10–11 | 規定・攻略の調査（済）、要求仕様、部品の選定 | 開発環境の構築 | 練習コースを用意（ショートトラック） |
| 2026/11 | | | **全日本学生大会 (11/21–22) を見学** |

| 2027/01 | 基板レイアウト、機構 CAD | ドライバ層（ADC、エンコーダ、IMU、PWM、ログ） | |

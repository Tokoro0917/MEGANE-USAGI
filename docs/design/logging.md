# 走行ログ

## 結論（2026-10-21 検討）

- **RAM だけでは、走行全体を細かく（1kHz）記録するには足りない**。1kHz で記録できるのは数秒
- → **外付けの SPI フラッシュ（16MB 級）を載せて、走行中に書き込む** 案をすすめる。5 回の走行すべてを 1kHz で残せる

## STM32H725 の RAM の内訳

ST の製品ページ（https://www.st.com/en/microcontrollers-microprocessors/stm32h725rg.html ）より。合計 564KB だが、1 つの塊ではない。

| 領域 | 大きさ | 使い方の案 |
|---|---|---|
| ITCM（専用） | 64KB | 速く動かしたいコード（割り込み、制御） |
| ITCM / AXI で共有 | 192KB | AXI SRAM 側に割り当てて、ログに使う |
| AXI SRAM（専用） | 128KB | ログ |
| DTCM | 128KB | 制御の変数、スタック、**コースの地図と経路**（仮想ライントレース） |
| AHB SRAM | 48KB | DMA のバッファ（AD7490、IMU、SPI フラッシュ） |
| バックアップ SRAM | 4KB | — |

- 地図（60m を 2cm ごと = 3,000 点 × 16 バイト）で約 48KB、経路と速度計画で同じくらい → DTCM に収まる
- **ログに使えるのは AXI SRAM の約 300KB**

## 1 回の走行の長さ

- 1 走目（探索）: コース最大 60m を 1.5 m/s 前後で走ると **約 40 秒**
- 2 走目以降: 10〜20 秒
- 持ち時間 3 分で最大 5 回。合計で 2 分前後

## 記録する項目（案）

| 項目 | 大きさ |
|---|---|
| 目標速度、実際の速度（左右） | 2 バイト × 4 |
| 目標角速度、ジャイロの角速度 | 2 バイト × 2 |
| モータの電流（左右）、duty（左右） | 2 バイト × 4 |
| ラインの横ずれ、マーカー・交差のフラグ | 2 ＋ 1 バイト |
| 位置 X、Y、向き（仮想ライントレース用） | 4 バイト × 3 |
| 走行距離 | 4 バイト |
| 電池の電圧、ファンの電流 | 2 バイト × 2 |
| **合計** | **約 48〜64 バイト** |

ラインセンサ 16 個の生の値も残すと、さらに 32 バイト増える（約 96 バイト）。

## RAM（300KB）に記録できる時間

| 1 回の大きさ | 250Hz | 500Hz | 1kHz |
|---|---|---|---|
| 32 バイト | 38 秒 | 19 秒 | 9.6 秒 |
| 48 バイト | 26 秒 | 13 秒 | 6.4 秒 |
| 64 バイト | 19 秒 | 9.6 秒 | 4.8 秒 |
| 96 バイト | 13 秒 | 6.4 秒 | 3.2 秒 |

- 1 走目（約 40 秒）を残すには、**32 バイト・250Hz（4ms ごと）まで落とす必要がある**。制御の調整（PID のゲインなど）に使うには粗い
- 加減速やコースアウトの瞬間を細かく見たいときは、1kHz で数秒分だけ残す「区間指定」になる

## 案: 外付けの SPI フラッシュ

上位機では、白鷺と Aventador が W25Q64（8MB の SPI フラッシュ）、LN5.8/LN5.9 と Tempestoso が FRAM、X-304 が「大容量メモリ」にログを取っている（[survey.md](../survey.md)）。

| 記録の仕方 | 16MB に記録できる時間 |
|---|---|
| 64 バイト・1kHz（約 63KB/s） | 約 260 秒 |
| 96 バイト・1kHz（約 94KB/s） | 約 175 秒 |
| 64 バイト・4kHz（約 250KB/s） | 約 66 秒 |

- **64 バイト・1kHz なら、5 回の走行（約 2 分）をすべて残せる**
- 走行中は、RAM に 2 つのバッファ（例: 4KB × 2）を用意し、片方がいっぱいになったら DMA で SPI フラッシュに書く（制御の処理を止めない）
- **フラッシュは書く前に消去が必要**で、消去には時間がかかる（64KB のブロックで約 0.15 秒、全体の消去は数十秒）。**競技の前（持ち時間の外）に、ログの領域を消しておく**
- 電源を切ってもログが残るので、競技のあとで PC に吸い出して見られる
- ピン: SPI の 4 本（SCK、MISO、MOSI、CS）。マイコンのピンの見積もりは 36〜43 本になり、46 本に収まる（[mcu.md](mcu.md)）
- 重さはほとんど増えない（0.1g 前後）

### ほかの選択肢

| 方式 | 長所 | 短所 |
|---|---|---|
| SPI フラッシュ（W25Q128 など、16MB） | 大きい、安い、電源を切っても残る | 書く前に消去が必要 |
| FRAM（512KB 級） | 消去が要らず、速い。電源を切っても残る | 小さい（1kHz・64 バイトで 8 秒程度） |
| QSPI PSRAM（8MB 級） | 消去が要らず、速い | 電源を切ると消える（走行のあと、電源を切る前に吸い出す必要がある） |
| 内蔵 Flash（1MB） | 部品が要らない | 書き込み中は動作が止まることがあるので、**走行中には書けない**（走行のあとに RAM から書き写すだけ） |

## 次に決めること

- 外付けのメモリを載せるか（すすめるのは SPI フラッシュ 16MB 級）
- 記録する項目と周期（制御の設計と合わせて決める）
- ログを PC で見るツール（`tools/`）

# 駆動系の検討: 1 輪あたり 3 モータ

## ねらい

**安いモータを使って、加速度を上げる。**
1 つのホイールギア（スパー）に、3 つのピニオン（モータ）を噛み合わせる。

```
            [M2]
              ●
     [M3]●    ◎    ●[M1]     ◎ = 車軸とスパー、● = ピニオン
              |
          ===タイヤ===
    ─────────────────── 床（車軸の真下にはモータを置けない）
```

- 同じ輪の 3 個は同時に同じ指令で回す。エンコーダは 1 輪に 1 個（車軸側に AS5047P）
- 制御上は普通の 2 輪差動駆動と同じ

## 前提（2026-10-20）

- **機体重量 100g 以下**（[mass.md](mass.md)）
- **吸引 600gf**（[suction.md](suction.md)）→ グリップの上限は約 69 m/s²（μ = 1.0）
- **電源 2S**（[power.md](power.md)）

## 採用モータ: NFP-D8620-3665-3-7.4（KOGUMA-Mk4 と同じ）

出典: [Tokoro0917/KOGUMA-Mk4](https://github.com/Tokoro0917/KOGUMA-Mk4) の `docs/spec.md`（販売ページ: https://nfpshop.com/product/8-6-x-20mm-coreless-dc-motor-high-efficiency-low-noise ）

| 項目 | 値 |
|---|---|
| 定格電圧 | 7.4V |
| 巻線抵抗 | 1Ω |
| トルク定数 | 1.47 mNm/A |
| 無負荷回転数 / 無負荷電流 | 46,000rpm / 140mA |
| 停止トルク / 停止電流 | 10.7 mNm / 7.41A |
| 重さ / 大きさ | 5.3g / φ8.6 × 20mm |
| 軸 | φ1.2mm、長さ 5.1mm、片軸（モータ側にエンコーダは付かない） |

- **受注生産で約 4 週間かかる**。6 個＋予備を早めに注文する
- 連続で流してよい電流は公表されていない → ドライバで電流を測り、ソフトで制限する（Mk4 と同じ方針）
- Mk4 の足回り（m0.3 のギア、LF-630、AS5047P）の設計資産を流用できる

## 見積もり

`tools/drive_estimate.py` で計算した。条件は、電圧 7.4V、タイヤ φ20mm、効率 0.8、モータ以外 68g（3 個/輪で合計 100g）。
加速度の単位は m/s²。モータの上限で、グリップは考えていない。

| 減速比 | 電流上限/個 | 1個/輪 (79g) | 2個/輪 (89g) | **3個/輪 (100g)** |
|---|---|---|---|---|
| 3.15 (13T:41T) | 2A | 17.5 | 30.9 | 41.4 |
| **4.38 (13T:57T)** | **2.4A** | 29.6 | 52.2 | **70.0** |
| 5.0 | 2A | 27.8 | 49.0 | 65.8 |

0〜6 m/s のどの速度でもほぼ同じ値になる（このモータでは電圧に余裕があるため）。

## わかったこと

1. **吸引 600gf のグリップ（約 69 m/s²）を使い切るには、3 モータが必要**
   - 1 個/輪だと、グリップに届くには 1 個あたり 5A 以上流す必要がある。発熱が大きすぎる
   - 3 個/輪・減速比 4.38 なら、**1 個あたり 2.4A** でグリップの上限に届く
2. **3 個にすると、同じ加速度での発熱が 1/3 になる**
   - 1 個あたりの電流が 1/3 になるので、発熱 I²R の合計も 1/3
   - ロボトレースは 1 周 10〜20 秒の加減速を最大 5 回繰り返す。マウスより発熱の余裕が大事
3. **このモータでは、加速度を決めるのは電圧ではなく電流（＝発熱）**

## ギア比: 13T:57T（4.38）を提案

タイヤ φ20mm のとき、スパーを大きくすると床とのすき間がなくなる。

| スパー | 減速比 | スパーの歯先と床のすき間 | 車軸とモータの軸間 |
|---|---|---|---|
| 41T | 3.15 | 3.55mm | 8.10mm |
| 50T | 3.85 | 2.20mm | 9.45mm |
| **57T** | **4.38** | **1.15mm** | **10.50mm** |
| 60T | 4.62 | 0.70mm | 10.95mm |

- 57T で床まで 1.15mm（Mk4 は 1.05mm）。これ以上大きくすると床に近すぎる
- 減速比を上げたいときは、タイヤを大きくするのではなく（減速比/タイヤ半径 の比が同じなら、加速度は変わらない）、ピニオンを小さくする必要がある。ピニオンの最小は、軸 φ1.2mm に付けられる歯数で決まる
- 無負荷の最高速は約 11.5 m/s。走行で使う速度（〜6 m/s）には十分

## 配置の検討

- 13T:57T なら、車軸からモータ中心までは 10.5mm。モータ同士がぶつからない角度の間隔は **約 48° 以上**（2 × asin(4.3 / 10.5)）
- タイヤ φ20mm だと車軸の高さは 10mm。**車軸の真下には置けない**（モータの下端が床にぶつかる）
- → 例: 前（0°）・上（90°）・後ろ（180°）の 3 か所。前と後ろは、モータの下端が床から約 5.7mm
- 吸引ファン、ラインセンサ、基板との干渉は、機体全体の配置の中で確認する

## 注意点

| 項目 | 内容 |
|---|---|
| 電流 | 3 個/輪、2.4A/個で、ピーク時に合計約 14A |
| ドライバ | 1 輪あたり約 7A。モータ 1 個ずつにドライバを付けるか、1 輪に 1 個の大電流ドライバにするかは検討中（[power.md](power.md)） |
| ギア精度 | 3 か所の軸間距離がずれると、ガタや引っかかりが出る。Mk4 と同じく、軸受とモータを 1 部品で持つマウントにする |
| 負荷の偏り | ギアでつながっているので回転は揃うが、特性の差で電流が偏る。同じロットで揃える |

## 進め方

関西地区大会での完走を危うくしないように、**「3 個まで載せられるが、1 個でも走れる」設計** にする。

1. NFP-D8620 を **7 個（走行 6＋ファン 1）＋予備で注文**（受注生産で約 4 週間）
2. 届いたら 1 個で、無負荷回転数、電流、発熱（2.4A を何秒流せるか）を測る → `drive_estimate.py` の電流上限を決める
3. 3D プリンタで、片輪分の 3 モータマウントを試作する（Mk4 の `mechanical/motor_mount/mount.py` がベースにできる）。噛み合わせ、電流の偏り、発熱を確認する
4. タイヤの μ を測って、グリップの上限を確定させる

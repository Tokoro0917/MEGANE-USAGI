## 傾向

| 項目 | 傾向 |
|---|---|
| 走行用モータ | Maxon DCX14L の 1 輪 1 個が主流（10 台）。軽い機体は DCX10L・12L。優勝機 APOLLON は Maxon のブラシレス |
| 1 輪に複数モータ | **generic（遠藤隆記・極東技術結社）が明記されている唯一の例**（1 輪 2 個、2S、125〜130g、全日本 3 位）。**1 輪 3 個は前例なし** |
| 電池 | 上位ほど高電圧（4S が多く、6S も出てきた）。容量は **300mAh が最多**。2S は generic、VLT-2、SimpleTracer、DragonFly（いずれも小型モータ） |
| 吸引 | 上位は全機あり。ファンはドローン用コアレス（8520、1020）が多数派、2025〜26 年はブラシレスが増加。**吸引力（gf）を書いた機体はない**（SimpleTracer の「負圧 100g/W 程度」が唯一の目安） |
| 重量 | 96〜240g。全日本 2025 上位 8 台の中央値は約 180g。**100g 以下は VLT-2（96g）だけ** |
| 加速度（申告） | 15 m/s² が最多。35 以上は APOLLON（35〜50）、generic（35）、LN5.9（55）だけ |
| ラインセンサ | 16 個が最多（10〜28 個）。generic は 4 個＋モータで動かすセンサアーム |
| IMU | ST の LSM6DSR / DSRX / DSV16X がほぼ独占 |
| タイヤ | φ22〜26mm、幅 10〜15mm が大半。スポンジ＋シリコンシートの自作が定番 |
| CPU | STM32 が最多。上位常連は Renesas RX が多い |

## 私たちの案との比較

1. **最も近い前例は generic**: 2S、ドローン用コアレス（NFP-D8620 と同じ級）を 1 輪に 2 個、2 輪、125〜130g で全日本 3 位。1 輪に複数のコアレスを使う考え方は上位で実績がある。ドライバは A4955＋外付け FET
2. **1 輪 3 個（計 6 個）は前例がない**。モータ 31.8g の重さを加速度で取り返せるかが論点
3. **100g 以下は上位機よりかなり軽い**（前例は VLT-2 の 96g、関西 2025 で 3 位）。上位の主流は、軽さより 4S〜6S と DCX14L の出力で速さを取る流れ
4. **加速度の見積もり（約 69〜73 m/s²）は、どの機体の申告値より高い**（最大は LN5.9 の 55）。申告値の測り方は不明。グリップで頭打ちになる点は [drive.md](design/drive.md) の分析どおり。吸引力を gf で公表している機体はなく、600gf が多いか少ないかは比べられない
5. **2S 300mAh は前例がある**（generic、VLT-2 など）。300mAh は最多の容量
6. **DRV8262 は関西 2026 の 2 位 X-304 と 6 位 Tempestoso が使用**（どちらも DCX14L 1 個/輪、4S、DDV パッケージ）。3 個並列での使用は前例なし
7. タイヤ φ24mm は最多のサイズ。ファンを NFP-D8620 で回すのは、8520 コアレスを使う多数派と同じ系統

## 参考になる工夫

- **センサ基板をマグネットコネクタで外れるようにする**（X-303、X-304）: 衝突で壊れにくい
- **IMU を緩衝材の上の別基板に載せる**（X-303）: 吸引ファンの振動対策
- **吸引モータに直列にインダクタを入れる**（LineLumen）: コアレスのインダクタンスが小さく、電流リップルと発熱が出たため
- **走行ログを大容量メモリに取り、専用アプリで解析する**（X-304）
- **吸引の荷重をリアルタイムで測るセンサ**（LN5.8）
- **1 走目に XY 座標のマップを作り、2 走目は仮想の目標点を追う「仮想ライントレース」**（VLT-2）
- **Out-In-Out の経路を数理最適化で作る**（APOLLON）。ラインから外れない範囲でショートカットする機体も複数

## 寸法について

規定 1-3 は「走行中の床面への投影が **直径 25cm の円** に収まる」（公式の原文で確認済み）。
幅 240〜250mm と申告している機体が 5 台ある（VLT-2 の 170×245 など）。長方形なら対角が 25cm を超えるが、**十字形や T 字形のように角を落とした形なら、外接する長方形が 25cm 角に近くても円に収まる**。幅の広いセンサバーを円の中心寄りに置く形と考えられる。外形を決めるときは、長方形の外寸ではなく円に入るかで確認する。
